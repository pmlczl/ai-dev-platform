MVP 实施路线图
1. 第一迭代：基础平台搭建
   建议 1 周
   - 部署 FastAPI、LangGraph、PostgreSQL。
   - 建设项目和任务管理功能。
   - 接入 GitLab。
   - 建立项目目录和中间文件管理机制。
   - 实现人工审批和工作流暂停、恢复。
   验收： 能够创建项目、上传 PRD、启动工作流、暂停等待人工审核。
2. 第二迭代：技术设计智能体
   建议 1 周
   - 接入 GLM 模型服务或合规的编码工具运行环境。
   - 开发代码仓库分析能力。
   - 开发 SDD 文档生成能力。
   - 开发结构化开发任务清单生成能力。
   - 开发设计质量检查能力。
   验收： 输入 PRD 和代码仓库，能够生成完整 SDD 和开发任务清单，人工审核后形成正式设计基线。
3. 第三迭代：开发实现智能体
   建议 1～2 周
   - 集成 OpenHands 或 CLI 编码 Agent。
   - 开发开发任务调度功能。
   - 实现代码修改和单元测试生成。
   - 实现自动编译、测试、失败修复。
   - 实现代码审查和成果包生成。
   验收： 输入已审核的 SDD，能够在隔离环境中完成代码开发、单元测试和构建验证。
4. 第四迭代：完整闭环联调
   建议 1 周
   - 串联技术设计和开发实现工作流。
   - 接入飞书通知。
   - 完善人工审核和修改机制。
   - 完善失败恢复、执行日志。
   - 使用真实研发任务开展验证。
   验收： 完成 PRD → SDD → 人工审核 → 代码开发 → 单元测试 → 人工审核的完整闭环。
